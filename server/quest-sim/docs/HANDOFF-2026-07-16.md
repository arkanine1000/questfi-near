## DEMO-ONLY features & allowances (revisit for production)

- **Betting is entirely client-side simulated**: localStorage wallet
  (auto-refills to 1,000 ⬡ when broke at a new world), per-world slips,
  odds from a hash-seeded house pool that drifts with kills/hp. No server
  state, no real market, no multi-spectator shared pool, stakes on
  abandoned worlds silently vanish. A real version needs a backend book.
- **No auth on spectator controls**: anyone who can reach the API can
  pause/run/new-season/start any world. Agent actions are token-gated,
  but observations of HOSTED agents are public, there's no rate limiting,
  and BYO join is open (name-squatting possible). Fine for a demo booth,
  not for an open deployment.
- **CORS defaults to `*`**; single-process, in-memory world registry with
  JSON-on-disk persistence (no DB, no horizontal scale, no world GC —
  `data/worlds/` grows forever).
- **Skeleton sprite is the declared placeholder for ALL agents**; rival
  colors come from a 10-color palette that wraps past 10 agents.
- **Scale ceiling**: LLM fan-out is threads capped at `LLM_CONCURRENCY=16`
  (`agents/sandbox/agent.py`) — a 100+ roster queues within the tick;
  moving to async litellm is the known next step. Tick pacing (2s) and
  the SSE full-frame payload (whole roster + events per tick) also want
  revisiting at 100+ agents.
- **Solo quest items are repurposed in the sandbox**: misc objective
  tokens (Crown of the Hollow King, The Vault Seal) become wearable +1/+2
  AC relics at site instantiation — there IS no retrieve objective here,
  and inert loot confused LLM agents into equip loops. If sandbox-native
  quest mechanics arrive later, revisit this conversion.
- **Balance knobs are demo-tuned**: boss 70hp/AC15, loot tiers +3..+6,
  policy `gear_at` thresholds, curated seeds — all tuned via the policy
  fleet, not against LLM behavior (LLM seasons are non-deterministic).
- **Legacy solo flow** is preserved at `?view=legacy` and must keep
  working (several crawler files are shared; every sandbox change went
  through additive seams: `agentLayer`, `agentsLayer`, `weaponTint`,
  `adaptSiteMapData`, `useGameOptional`, `isEntrance`).
- The `.env` in quest-sim carries live-looking API keys — never commit
  derivatives of it, never include it in deploy artifacts.

  spectators.

  every tick indefinitely until someone wins or the 300-tick bell. Add a
  per-season token/call budget (and surface it in /state) before leaving
  LLM worlds unattended in public.

  codify it (build command, output dir, env) once the project exists.
- `data/worlds/` and per-agent `memory/*.jsonl` grow without bound; add
  retention/GC before any long-lived deployment.
- Policy-brain flavor lines and LLM thoughts share the agent_thought
  channel — if mixed-brain seasons ever ship, consider labeling the
  source so spectators can tell scripted flavor from real reasoning.
